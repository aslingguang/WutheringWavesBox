# 安全与隐私

## 1. 信任边界

- Renderer 内容按不可信处理
- 网络响应按不可信处理
- 用户导入的 JSON、URL 和文件按不可信处理
- Helper 只接受 Main 启动的受控通信通道
- 游戏目录可能包含符号链接、异常路径和被占用文件

### 账号边界

- 当前档案不保存密码、验证码、Cookie 或 OAuth Code，UID 仅用于本地展示。
- 启动器缓存中的 OAuth Code 仅保存在 Electron Main 内存中，用于请求库洛官方角色接口；不写数据库、不记录日志、不暴露给 Renderer。
- 抽卡链接输入框会按用户要求在 Renderer 中短暂显示完整链接；仅用于主动分析或复制，不持久化，也不得出现在异常消息和开发日志中。
- 本项目不向第三方账号服务上传抽卡记录；历史数据保存在本地 SQLite，并支持本地导出和截图快照。
- 抽卡头像只允许 Electron Main 从固定的 `leck995/WutheringWavesToolResources` 仓库下载，校验 Content-Type 和 2 MB 大小上限后缓存；Renderer 仅接收 Data URL，CSP 不放宽。
- 禁止将账号密码发送到非官方第三方服务。新增登录只允许接入经过验证的库洛官方验证码或浏览器授权流程。
- 档案切换不会改写官方启动器缓存；后续若保存令牌，必须使用 Electron `safeStorage`，且不得暴露给 Renderer。
- 官方启动器账号切换属于高风险文件写入，实现前必须完成格式验证、原文件备份和原子恢复。

### 兑换码边界

- Electron Main 通过固定 HTTPS 地址获取数据，Renderer 不能指定任意 URL。
- 响应经过长度、字符集及结构校验，请求有 5 秒超时和 10 分钟内存缓存。
- 社区兑换码数据源不宣称为官方数据，也不发送本机账号信息。
- 证书域名不匹配时直接降级为空结果，禁止使用 `NODE_TLS_REJECT_UNAUTHORIZED=0` 或自定义跳过校验。

## 2. Electron 基线

```ts
webPreferences: {
  contextIsolation: true,
  nodeIntegration: false,
  sandbox: true,
  webSecurity: true,
  preload: preloadPath
}
```

- 设置严格 CSP，不允许 `unsafe-eval`
- 禁止任意远程页面在主窗口中运行
- 外部链接通过白名单校验后交给系统浏览器
- 拒绝新窗口、导航、权限申请和未知协议
- 生产包不启用远程调试端口
- IPC Handler 必须校验事件来源窗口

## 3. 凭据保护

- 优先使用 Windows Credential Manager；也可使用当前用户范围 DPAPI
- 数据库保存凭据引用 ID，不保存密文主体更易管理生命周期
- 切换账号时明文只在 Helper 内短暂存在
- 用完后尽早释放缓冲区，禁止写入异常详情
- 删除账号时同时删除关联安全凭据
- 不支持静默导出凭据

## 4. 日志脱敏

必须过滤：

- `token`、`cookie`、`authorization`
- 登录票据、设备标识和手机号
- 抽卡 URL 的查询参数
- 用户名目录和不必要的完整路径

日志采用结构化事件和错误码。用户导出诊断包前再次执行脱敏扫描。

完整抽卡 URL 不得返回 Renderer、写入 SQLite 或进入日志。Helper 将 URL 仅返回 Main，Main 在用户主动点击后写入剪贴板，并把不含 URL 的成功/失败结果返回页面。

## 5. 文件写入安全

- 写入前解析并校验最终绝对路径
- 不接受 Renderer 传入的任意目标路径和任意内容组合
- 使用允许的根目录和业务方法约束写操作
- 账号切换先备份，再写临时文件，校验后原子替换
- 游戏更新校验 Hash 和签名/可信来源后才能替换文件
- 禁止跟随越出允许根目录的符号链接

## 6. 网络安全

- 仅使用 HTTPS
- 每个服务设置连接和总超时
- 限制响应体大小、重定向次数和下载目标
- 对非官方 API 使用适配器和功能开关
- 远端配置不得下发可执行命令、任意脚本或任意文件路径

## 7. 发布安全

- Windows 安装包和 Helper 均应代码签名
- 更新清单必须可验证，生产环境禁止降级到未签名更新
- CI 使用锁文件和依赖审计
- 发布产物生成 SHA-256 校验值和 SBOM
