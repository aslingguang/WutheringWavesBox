# 版本信息维护

版本总结所用的版本号、版本名称和开始时间支持自动更新与手动维护。

## 数据源

只使用鸣潮官网新闻数据：

- 从“版本内容说明”公告标题提取版本号和版本名称。
- 从同版本“版本更新维护预告”正文的“更新维护时间”提取维护开始时间，作为版本开始时间。
- 官网没有覆盖的条目保留本地信息。
- V1.0 固定以“鸣潮往复，文明不屈”、`2024-05-23 10:00:00` 作为版本历史基线。

官网只更新版本号、名称和开始时间；本地分期和 UP 角色/武器 ID 会被保留。

## 冲突处理

自动更新先生成预览。版本名或开始时间与本地不同时，界面提供三个选择：

- 覆盖冲突信息：使用优先级最高的网站数据，并更新无冲突条目。
- 不覆盖冲突信息：保留冲突版本的本地内容，仅添加或更新无冲突条目。
- 不更新：放弃本次抓取结果，不写入磁盘。

版本信息保存在 Electron `userData/version-metadata.json`。“版本管理”支持添加、修改和删除；保存相同版本号会更新该版本，结束时间由相邻版本的开始时间自动推导。

版本总结默认只展示当前 UID 有唤取记录的版本；“显示所有版本”可以展示全部已知版本及其零记录状态。V1.0 的修改、删除入口保持可见但禁用。
